## 1. 目标、边界与现状

用户在 P01 完成：定义检索范围 → 比较场景覆盖 → 收集场景 → 核对获取清单 → 保存工程选择或启动下载 → 查看进度与恢复失败。
页面输出有身份、来源、文件角色和状态的数据引用；是否可处理由 P02 验证。

沿用 Vue/Quasar、Leaflet、ASF、DownloadService、aria2c、Library 和既有后台尝试模型。本轮不改 P02—P05 布局、不决定 phase stack/looks/滤波/参考影像、不扩展 NISAR Range、新增科学运行或改 Qt/安装入口。D01 不阻挡本页。

## 2. 布局与信息层级

P01 内有“检索 / 下载管理”两个子视图，全局下载按钮和 Jobs 入口定位到同一下载视图，不新增第六个流程页面。保留公共 Logo、语言/主题、工程导航、Inspector 和后台状态栏；仅接入 P01 所需导航，不趁机重构其他四页。

桌面布局草图（表示关系，不是产品截图）：

~~~text
公共外壳 / 当前工程                         下载活动数
P01 检索与下载              [检索] [下载管理]
┌────────────────┬──────────────────────────────────┐
│ 检索条件 280px │ 纯影像地图 · 工具 · 图例          │
│ 卫星 / 日期    │ AOI / footprint / 已选覆盖        │
│ AOI / 轨道     ├──────────────────────────────────┤
│ 极化           │ 结果摘要 / 分组错误 / 场景表       │
│ 检索 / 重置    │ 已加载数量 / 分页                 │
└────────────────┴──────────────────────────────────┘
已选 N 景 · 已知体积 + 未知项  [清单] [仅下载/创建/添加]
Inspector 按需展开；已选抽屉与详情不并列常驻
~~~

- 主区域左侧条件栏 280px，右侧地图默认约 420px 高，下方结果；内容区可独立滚动。
- 固定选择栏仅在 P01 检索子视图显示，内容底部预留高度，不遮挡表格和分页。
- 可用内容宽度低于 1000px 时筛选改抽屉，地图/结果上下排列；Inspector 用覆盖方式呈现，关闭后返回原焦点。
- 结果表内部横向滚动或折叠次要字段，整页不横向溢出。抽屉标题和操作栏固定，列表内部滚动。
- 顶部下载数指活动获取批次，不把父子尝试相加成多次活动下载。
- 不强制跳至下一页；保存成功后提供“查看下载”和“前往数据与准备”入口。

### 筛选区

| 字段 | 默认与行为 |
|---|---|
| Mission | 默认 Sentinel-1；保留 NISAR/All 原有入口 |
| 卫星 | A/B/C/D 全选、可多选；空选就地报错并禁止提交 |
| 产品/模式 | 明确只读显示 SLC / IW，对应当前 TOPS 输入；不提供 EW/SM |
| 日期 | 最近 90 天，UTC 起止日期；全天范围与服务端包含边界一致，不能漏掉结束日末尾亚秒记录 |
| 轨道方向 | 不限/升轨/降轨 |
| 相对轨道 | 可空，整数 1—175 |
| 极化 | 不限及现有 VV、VH、VV+VH，忠实传给 provider；不暗示请求改变产品所含通道 |
| AOI | 必填，见下一节 |

前端优先使用能力接口生成选项，后端仍校验全部输入。若依赖不支持选中的卫星，明确要求调整选择或更新依赖；不能静默删掉卫星。All 下 Sentinel/NISAR 保留独立筛选语义和结果分组，混合选择只能仅下载，不能绑定一个处理工程。

改条件不自动检索；显示“条件已修改，尚未重新检索”，结果摘要保留产生该结果的条件。重置仅恢复筛选默认值并清除 AOI 草稿/应用状态、结果及查询，不清空选择篮。清空已选是单独且明确的操作。

## 3. AOI、地图、场景与状态

### AOI 与地图

- 保留两点框选、BBOX、WKT、KML/Shapefile。文件选择浏览服务主机，显示规范化 Linux 路径及输入来源；支持现有 Windows/WSL 可验证路径转换，不上传 SAR 大文件。
- BBOX 标明西、南、东、北；WKT 标明 WGS84 经度/纬度。保留单个 Point/LineString/Polygon；点线检索可用但不冒充处理面积 AOI。
- 草稿、已应用几何、最后查询快照分开。应用成功才替换地图 AOI；应用失败保留旧几何并标记草稿错误。检索必须使用当前草稿成功解析的结果。
- 不新增多边形手绘、地址搜索或复杂几何编辑。拒绝非法、自交、多几何及跨日期变更线输入；不自动修复成另一个区域。
- KML 按其坐标约定读取；Shapefile 必需侧车和 CRS 可核验，未识别/非本轮支持 CRS 时解释错误。不能静默取第一个要素、丢孔洞或把投影米坐标当经纬度。
- 地图绘制限于可显示区域，文本 AOI 校验与地图投影可显示范围分别反馈，不能通过显示截断悄悄改查询几何。
- 工具提供框选/取消、定位 AOI、定位结果；Esc 取消绘制。首次应用或显式定位可调整视角，选择/分页更新不抢视角。
- 只使用现有纯影像底图与必要署名；失败显示空底、错误提示和重试按钮，几何层及结果表仍可用。恢复后清除错误提示，不加街道或地名 fallback。
- AOI 橙色、普通 footprint 青色、已选黄色；以线宽/图例/文字辅助，不只依赖颜色。没有 footprint 的场景显示“无覆盖几何”，仍可查看与选择。
- 点击 footprint 只聚焦详情；重叠覆盖列出候选（卫星、日期、轨道、ID），由用户查看/勾选。表格选择同步地图；列表提供地图操作的键盘替代。
- footprint 相交不等于共同 IW/burst 范围；本页下载完整 SLC，不使用“AOI/burst 子集下载”措辞。未经可靠计算不展示覆盖百分比。

### 场景表与独立已选清单

主列为选择、卫星、成像 UTC 时间、相对轨道、方向、极化、大小和获取状态。完整产品 ID 在可展开详情中可复制；排序只针对已加载结果时明确标注。

场景键为 provider_id + remote_product_id，不用日期、文件名或单独 remote ID 合并。结果页加载 50 景，保留加载更多；总量未知则只显示已加载数量。全选已加载以追加方式加入选择篮，最多 1000 景；超限时不做不明确的部分选中。

选择篮跨检索、分页、mission 切换、子视图切换及刷新保留，按全局或 project_id 隔离。本机浏览器存储仅保留非秘密筛选/选择元数据和来源，不存下载凭据/签名 URL。恢复后向服务端解析身份；已失效或无法解析项保留可见原因，移除或修复后才能提交。

篮中标明来自哪个查询、是否不在当前结果、是否缺少获取能力、已有本地数据或活动下载。检查详情不勾选，勾选不自动开启详情。结果“取消选择”与“清空全部已选”名称区分，后者作用于整个篮。

### 页面状态与异步约束

| 状态 | 可观察行为 |
|---|---|
| 初始 | 显示 AOI/日期指引，不把尚未查询写成零结果 |
| 查询中 | 保留旧结果和篮；标明加载，避免重复提交同一请求 |
| 空结果 | 展示实际查询摘要和修改条件入口 |
| All 部分失败 | 按 mission 显示错误；成功结果与篮不丢失 |
| 查询失败 | 保留上一份成功结果并明确其旧时间/条件，不冒充本次结果 |
| 条件变化 | 标明未查询；用户主动发起新查询 |
| 翻页 | 使用所属查询的冻结条件；追加时按复合身份去重 |
| 断连/恢复 | 标明数据更新时间；禁用依赖在线服务的提交，恢复后重新核对 |
| 空选择 | 三种提交入口禁用并解释需要先选场景 |
| 选择失效 | 明确问题项；不静默丢弃或替换 |

AOI、query、pagination 都绑定上下文 ID 与递增请求版本；变更、重置或离开上下文使旧响应失效。可取消网络请求以节省资源，但正确性依靠版本校验。旧响应不得改结果、AOI、selection、busy/error；同一查询翻页不并发重复追加。

## 4. 提交清单、下载控制与 P02 合同

### 三种入口的统一清单

三种入口先进入同一预览：场景、完整 SLC、可勾选 EOF/DEM、保存位置、已存在项、活动任务、待获取项、已知大小与未知数量、环境状态、阻断项。EOF 建议默认勾选、DEM 建议默认不勾选；勾选后按批次自动获取，范围/依赖见补充稿。默认现有共享 Library，不新增逐批下载根目录。

| 入口 | 确认动作 | 工程与下载作用 |
|---|---|---|
| 仅下载 | 开始下载 | 不创建工程，发布到 Library |
| 从选择创建工程 | 保存选择，稍后下载 / 保存并开始下载 | 输入名称和服务主机目录，Profile 从单一 mission 确定 |
| 添加当前工程 | 保存选择，稍后下载 / 保存并开始下载 | 显示目标工程，检查 Profile/revision，保留现有输入 |

保存选择与下载动作不能由隐藏默认值决定；预览取消不创建工程、不绑定输入、不排队。缺 aria2c/凭据时仍可保存工程选择；只有开始下载受准备条件约束。凭据“已配置”不等于“认证成功”，错误中不暴露账号或秘密。

跨 Profile 拒绝，unassigned 工程首次绑定后锁定。重复项明确显示并复用，添加只增加新的选择，不替换已有 Dataset。多轨道等信息提示由 P02 检查，不在 P01 假装完成科学兼容验收。All 混合选择保留仅下载，创建/添加被禁用。

当前查询 AOI 仅作为获取来源快照。第一次或后续添加均不能悄悄覆盖工程处理 AOI，P02 显式选择其用途；跨次查询收集的场景分别保留来源。保存完成提供 P02 入口，下载中的远程占位状态可见但不能用作可处理输入。

### 获取计划与下载管理

批次列表提供全部（默认）、活动、已暂停、失败、已取消、已完成过滤，默认最近创建排序；每批次展示最新尝试，展开历史父子尝试。文件行显示角色、场景、路径、阶段、字节、速度/ETA、错误和已发布引用。保留现有约 3 秒轮询，控制后立即刷新；同一视图不重叠轮询。

计划先冻结所选产品、勾选的获取角色、DEM 覆盖策略及已知目标位置；未勾选角色显示未请求，不计完成分母。EOF 在尚未解析时显示“待解析”，不编造文件名、大小或独立文件数量；一个 EOF 可关联多个场景。解析得到的物理文件作为有来源的计划解析结果追加保留，不能无记录替换已发布内容。

阶段为排队、认证、等待数据锁、解析文件、传输、校验、发布；DEM 另有等待完整 SLC 几何和拼接阶段；有可靠报告才展示具体阶段，未知就标未知。已知总字节才有百分比，未知显示活动阶段；混有未知大小时批次体积标为已知小计+未知项，不猜总体百分比。停止后隐藏旧速度/ETA。

| 当前状态 | 可用动作与后果 |
|---|---|
| 排队/运行 | 暂停或取消；先显示正在停止，worker 退出确认后才到终态 |
| 暂停 | 继续建立关联新尝试；取消结束批次，保留文件 |
| 失败/取消 | 重试建立关联新尝试，校验后复用完整文件，partial 按 aria2c 续传规则处理 |
| 已完成 | 查看路径、资产与 P02 入口，不对终态尝试原地重跑 |
| 已接续 | 查看子尝试，不重复建立第二个子尝试 |
| 状态未知/断连 | 保留最后状态与时间，重连核对后恢复控制 |

暂停和取消均保留 partial、aria2 数据及已下载文件；不新增删除数据动作。失败应报告具体角色及原因。成功的 SLC 可独立发布，EOF 失败仍标批次未全部完成，P02 显示缺失项。校验、发布或本地导入失败不能靠文件存在就报成功。

### 接口与持久化缺口

沿用 /api/v1 和现有控制端点。新界面经 acquisition-preview / acquisition-commit 提交；旧 downloads / selection 保留兼容。下表记录原合同目标，实现差异与验证见第 6 节。

| 接口/模型 | 最小变化 |
|---|---|
| GET /data/capabilities | 提供显式 IW/SLC 和平台可用性/原因；保留任务分组 |
| POST /data/search | 统一平台、轨道、日期、模式验证；返回稳定身份和可靠元数据；前端请求版本防旧响应 |
| POST /data/aoi | 返回规范几何、CRS、来源及结构化错误；保留当前输入方式 |
| POST /data/acquisition-preview（新增） | 接收复合场景引用、查询/AOI 来源及工程目标；冻结预览并返回 plan_id、角色清单、可复用资产、准备问题，无下载/工程绑定副作用 |
| POST /data/downloads | 新调用引用 plan_id 与幂等键；服务端复核计划和环境，返回获取批次/尝试 |
| POST /data/selection | 引用 plan_id，携带是否开始下载和 expected_revision；返回 project/dataset/plan/job 及各部分状态 |
| GET /data/downloads 及控制响应 | 补批次、文件 ID、阶段、父子尝试、更新时间、发布资产关联；保留旧 status/display_status 兼容语义 |
| RemoteRef / LibraryRef / AcquisitionPlan | 复合身份、明确 SLC/EOF 角色、来源查询、内容版本和位置分离、校验依据 |

幂等键按操作与冻结内容校验：同键同请求返回已有结果，同键异请求返回冲突。服务端防重复建工程、绑定、启动任务；同场景不同批次遇到活动获取时关联现有获取，完成后各工程独立引用，不能只依赖文件锁制造多个排队副本。复用活动传输时展示原批次入口及关联工程；暂停/取消作用于该共享传输，控制区明确列出受影响工程，不伪装为只取消某一工程引用。

预览与提交间若工程 revision 或影响计划的场景元数据变化，返回冲突并要求刷新预览。提交过程中已保存选择但 worker 启动失败，响应须返回已保存的 project/dataset/plan 与失败尝试；重试不能再建一个工程。已完成文件经现有校验复用，内容变化生成新版本，不能覆盖旧资产。

旧 product_ids 请求保留兼容解析：唯一匹配才能转换为复合引用，歧义时拒绝。旧记录不破坏性重写；根据可信元数据补来源/角色，未知值保持未知，旧 stat 快照不变成强校验已通过。新增字段可读旧记录，保留控制和历史链接。

### P02 消费合同

三种入口统一提供场景复合身份、获取计划、查询/AOI 快照、文件角色、下载状态、Library asset_id/内容版本/位置及校验依据。仅下载先成为 Library 引用，之后添加工程仍保持同一来源语义。

远程已选、partial、已下载待校验、可用资产明确区分；可用只表示按记录完成获取和相应检查，不代表 TOPS 准备就绪。工程引用精确版本；下载完成形成新输入 revision，历史尝试/成果不改写。P02 继续负责参考影像、轨道/DEM 完整性、IW/burst 共同范围与处理 AOI，以及 DEM 高程基准/处理格式准备；P01 新增可选整景 DEM 获取，传递源版本、范围/余量、nodata 与原始高程基准，不能报处理就绪。P03—P05 本轮无合同实现变化。

## 6. 实现决策与验收

实现已交付，见[本轮记录](../handoff/records/2026-09-06-p01-implementation.md)。

- 提交统一使用 acquisition-commit；resolve-selection 核对恢复后的选择；旧下载与选择接口仍兼容。
- 同工程、同场景集合、同选项的活动提交复用批次；不同工程保留独立尝试，共享文件锁与校验后的 Library，只有一个实际源传输。取消只影响所属尝试。
- 获取计划固定网络策略；全局最多两个传输槽，均衡每个 SLC 四连接，稳定模式两个连接且批内单景；无可信 ETag 时不续接旧分片，SLC 降为单连接。
- 重试创建新尝试，文件按完整性与身份复用。源文件与轨道校验 receipt 置于 .integrity，坏文件置于 .invalid，EOF 下载中间文件置于 .partial，避免 ISCE2 通配误选。
- DEM 先按目录 footprint 预览；SLC 完成后读取全部 IW 元数据复核。超过预览瓦片集合要求重新预览；重新预览能使用已下载完整几何。
- 地图候选、筛选、预览和下载页保留操作与必要状态，详细诊断折叠在“详情”。

用户科学输入、参数及数值算法未改。P02—P05 未实施。真实 ASF 整景认证下载、带宽饱和、
压力规模和原生 125%/150% 缩放仍需单独证据。
