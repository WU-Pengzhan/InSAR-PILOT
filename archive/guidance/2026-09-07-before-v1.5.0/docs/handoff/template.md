# 单次任务交接记录模板

[统一索引](index.md)

复制以下内容到 `docs/handoff/records/YYYY-MM-DD-p0N-topic.md`，替换占位符。
这只是模板，不是已完成的任务记录；旧记录追加保留。

```markdown
# P0N｜页面名称｜本次任务
日期：
本次用户指令与范围：
阶段：设计 / 实现 / 修复 / 验收
页面任务卡：写相对链接
上一份记录：若无，明确写无

## 接受的决定与仍未知的事项
- 已接受（来源/日期）：
- 本次新增决定：
- 尚未确认；影响哪些工作：
- 不受阻、可独立继续的工作：

## 实际完成
- 用户可观察的行为或设计结论：
- 代码/设计文档路径：
- 复用内容与新改动：
- 未完成内容：
- 跨页输入/输出/API 变化及兼容影响：

## 验证与证据
- 实际命令、环境、结果和证据路径：
- 模拟/fixture 与真实数据验证的区别：
- 未执行检查及原因：
- 科学参数、历史数据和已发布成果是否改变：

## 服务与任务
- 本次启动的服务/worker/下载：身份、端口、临时目录，或明确写未启动
- 当前状态：已清理 / 仍运行 / 未探测
- 用户服务是否操作、原因与结果：
- 不记录 token、凭据或秘密环境变量

## 下一步
- 下一位先读：
- 精确下一动作：
- 待用户决定（仅必要的未决项）：
- 更新索引、任务卡、current 与 migration 的情况：
```
