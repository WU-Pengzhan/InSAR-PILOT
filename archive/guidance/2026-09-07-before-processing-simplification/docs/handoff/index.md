## 交接更新规则

每次任务结束，包含仅设计、部分完成、失败或被阻断的情况，都必须：

1. 新建一份[交接记录](template.md)，保存到 `docs/handoff/records/YYYY-MM-DD-p0N-topic.md`；同名已有文件时换新名称，不覆盖旧记录。
2. 更新本页任务卡“最新交接”和本索引的状态、下一步、最近记录链接。
3. 更新 [current](current.md) 的当前位置和未决问题；实现变化同时更新 [migration](../architecture/migration.md)。
4. 若代码/API/测试文件移动，同步本页入口；若跨页合同变更，更新受影响页面卡并写明兼容与下游影响。
5. 最终答复给出实际完成、验证、限制和本次交接记录链接。

交接中的“已完成”要有实际依据。状态区分待设计、设计待评审、待实现、实现中、待验收、已验收；
存在阻断时单独列出原因和可独立继续的内容。用户已明确授权实现的范围不再重复要求批准。
