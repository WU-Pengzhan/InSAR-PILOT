# InSAR-PILOT 1.5.0

2026-09-08 · 本机 Web 工作台版本

## 面向用户的变化

- 默认打开 Web 工作台，统一工程首页、检索地图、下载中心、中英双语与明暗主题。
- 工程显式新建/打开/关闭，最近工程与简化的数据、处理、成果分区。
- Sentinel-1 A/B/C/D 检索、跨检索选择、三种获取入口、可选轨道与整景 DEM。
- 下载目标预览、校验后发布、来源复用、历史分页与暂停/继续/取消/重试。
- 浏览器直接访问本机服务；单窗口占用、关闭后接续，后台任务保持运行。
- README 与中英文手册重新围绕当前 Web 界面组织，安装与开发资料独立。

## 清理与安装变化

移除停止开发的 Qt 界面、桌面启动逻辑、Qt 依赖和专属测试，默认 `insar-pilot` 与 `python -m insar_pilot` 启动 Web。`insar-pilot-web` 保留。
wheel 与源码包包含编译后的 Web 资源。安装脚本仅安装应用，科学环境由用户维护。
旧工程服务、CLI、ISCE2 TOPS、ISCE3/NISAR/openSEPPO 与历史科学证据继续保留。旧 CLI 工程应导入新的 Web 工程，不与 Web 引擎交替写入同一工程。

## 版本边界

P01 和公共外壳已实现；P02—P05 专业页面仍待逐页设计。phase stack 确切合同尚未确认。真实账号长时下载/吞吐与完整科学流程有独立验收事项。
本轮不进行真实 SAR 运算，不修改官方算法、参数、黄金输入或历史失败。
当前验证与限制见[发行交接](https://github.com/WU-Pengzhan/InSAR-PILOT/blob/main/docs/handoff/records/2026-09-08-v1.5.0-finalization.md)。

## 获取与使用

安装 wheel 或解压源码包，参见[安装指南](https://github.com/WU-Pengzhan/InSAR-PILOT/blob/main/docs/installation.md)。`SHA256SUMS` 用于核对发行文件。

---

Version 1.5.0 makes the local Web workbench the default product. It includes the existing project and Sentinel-1 search/download experience, removes the retired Qt interface and dependencies, and reorganizes the documentation around the current UI.
The wheel and source archive bundle the compiled frontend. Scientific runtimes remain user-managed. Existing ISCE2, ISCE3/NISAR, openSEPPO and legacy CLI capabilities are retained.
The remaining four professional workflow pages, real-account sustained download acceptance and the precise phase-stack contract remain pending. No new scientific processing validation is claimed by this release.
