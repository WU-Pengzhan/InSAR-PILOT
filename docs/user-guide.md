# Web 工作台使用指南

## 工程入口

首页提供新建、打开和直接检索。新建时选择父目录并填写名称，打开时选择 `.pilot` 文件。最近工程帮助返回已有工作，启动时不会自动打开上次工程。
未打开工程也可检索下载。关闭工程不取消后台任务。单独复制 `.pilot` 不包含全部影像；便携备份与系统双击关联尚未交付。

## 界面布局

左侧为工程浏览器，中间为当前任务，右侧为对象属性。工程栏可调宽，属性栏可收起。顶部切换语言、主题、运行环境与下载入口，底部显示任务状态。

## 检索与下载

以 AOI、日期和任务专属条件筛选影像，Sentinel-1 A/B/C/D 可多选。地图覆盖用于选景，不表示已下载 burst 子集。底图失败时可保留条件与选择后重试。
已选清单跨检索保留。获取预览显示影像、可选 EOF/DEM 与目标位置：创建工程、加入工程、仅下载三个入口共用预览。
项目下载归入工程 data，仅下载进入共享 Library。切换工程不会改变已提交批次的目的地。
下载中心支持筛选、分页、暂停、继续、取消、重试。先前尝试保留，完成须有真实发布依据。
DEM 获取包含覆盖信息，科学处理的高程基准与完整兼容性由数据准备环节确认。

## 后续四个环节

数据与准备、参数与生成、运行、成果与 QC 是后续四个主入口。当前有基础输入、计划、任务与成果能力，尚未完成专业页面。导航入口不代表科学流程已验收。
phase stack 确切产品合同待确认，解缠、时序与广域科学数值对照暂缓。历史执行与失败不改写。

## 浏览器与后台

本机浏览器直接访问端口，一个窗口进入，其他窗口等待。正常关闭后自动接续，异常断开约 15 秒释放，重试可能再需数秒。
浏览器关闭不停止后台任务。显式退出前处理活动任务；运行环境页只检测，不安装环境。
