# 快速开始

完成[安装](installation.md)后，在浏览器中打开工作台。

1. **选择入口。** 新建工程、打开已有 `.pilot` 文件，或点击“检索”先寻找数据。
2. **定位研究区域。** 在“检索与下载”中绘制 AOI，或输入范围/使用区域文件。
3. **筛选影像。** 选择日期、Sentinel-1 卫星与所需条件，提交检索并比较地图覆盖和场景列表。
4. **保留选择。** 将需要的影像加入已选清单，继续检索时清单保持。
5. **预览获取。** 选择创建工程、加入工程或仅下载，核对位置以及可选轨道/高程数据，再提交。
6. **查看任务。** 在下载中心查看批次和保存位置，按需暂停、继续、取消或重试。

数据源需要认证时使用自己的合法账号。创建任务不等于影像已经可用，以实际完成与校验状态为准。
关闭浏览器后任务继续运行；使用顶部“退出应用”停止后台前，先处理活动任务。
