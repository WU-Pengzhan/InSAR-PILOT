## 实际改动

- 移除越点越多的 tabs 数组，固定五个主入口。首页、新建、文件、Library、Compute 等辅助视图不追加主标签。
- 下载归 P01 页内视图；步骤/任务/历史/事件归 P04；成果/QC/地图归 P05。
- 将原有参数/生成入口与步骤观察分别映射到 P03/P04，仅复用已有实现，不宣称后四页已完整开发。
- 打开工程先进入数据页，再异步读取；不会在加载完成后覆盖用户已经切换的页面。没有工程时保留五个入口，禁用需要工程的页面。
- 左侧分隔条可鼠标拖动和键盘调节，宽度 180—400 CSS px，默认 230，保存到本机偏好。拖动即时更新，快速刷新也保留。
- 工程树名称完整保留，支持内部横向/纵向滚动及 hover 全名；初始展开的节点在异步数据加载后仍能显示子项。
- 检索条件与地图使用接近等宽两列；地图以 4:3 为布局参考，小容器自适应单列。没有把整套页面强制锁为同一尺寸。
- 下载环境默认只显示一行配置状态；需要时展开程序、账户配置、Library/GDAL 等详情。账户已配置不表示远程认证已经通过。
- 原地图 tileerror 一旦发生便一直保持错误。现改为跟踪当前视野/当前缩放级别的瓦片，排除缓存与离屏瓦片，区别部分缺片、全部失败和加载中，恢复后清除提示。
- 保留底图重试、AOI/footprint 和既有获取/下载功能，没有修改科学参数或后端 API。
