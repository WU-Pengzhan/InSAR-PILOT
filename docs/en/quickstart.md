# Quickstart

After [installation](installation.md), open the workbench.

1. Create/open a project, or explore data first.
2. Draw your study area, enter bounds, or use an AOI file.
3. Select dates, satellites and filters; compare results with map coverage.
4. Keep scenes in the independent selection while refining searches.
5. Preview acquisition into a new project, existing project or shared Library. Check optional orbit/DEM data and destination, then submit.
6. Track, pause, resume, cancel or retry downloads from the task center.

Use your own authorized data-service credentials when required. Submitted tasks are not yet available imagery; inspect completion and validation status.
Closing the browser leaves background tasks running. Exit explicitly after handling active tasks.
1.5.0 focuses on projects and search/downloads; the remaining four pages are still being refined. Read the [user guide](user-guide.md).
