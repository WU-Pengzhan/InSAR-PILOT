## 产品案例与资料依据
本轮读取官方产品/设计文档；不是现场完整走查这些产品，也不复制其资产或地图标注。
抓取日期、HTTP 状态与摘录保存在 artifacts/project-p01-final-2026-09-07/design-sources.json。
个别请求首次遇到 TLS 错误，保持证书验证后重试成功；未成功的页面不作为依据。

## 信息架构
- 首页是工程入口：新建、打开、检索下载三个主操作，随后最近工程。
- 五个流程入口常驻；无工程时 P02—P05 禁用，P01 可独立完成下载。
- 工程树只突出数据、处理、成果与必要 QC；默认不把日志/事件/快照做成栏目。
- 当前工程由用户选择决定，不由后台最后活跃任务决定。异步响应不得抢回页面或混入另一工程。
- 顶栏负责工程上下文、语言/主题/退出；底栏负责引擎与任务状态。后台任务管理不等于取消/关闭工程。
- 属性面板首次默认收起，用户操作可保存偏好；首页/新建/打开/下载管理不展示空 Inspector。主动查看检索对象可展开。

## 视觉语言与令牌
平面界面以留白、细边界和文字层级分组，不叠加装饰背景或大型阴影。
源码令牌统一放在 frontend/src/style.css；Quasar 组件保持原有键盘语义。

| 令牌/规则 | 明亮 | 暗色 |
|---|---|---|
| 内容表面 | #ffffff | #18262f |
| 辅助区域背景 | #f3f6f8 | #111d25 |
| 主要文字 | #243746 | #e4edf2 |
| 次要文字 | #526571 | #acbec8 |
| 边界 | #d7e0e6 | #344650 |
| 强调色 | #08776c | #65d5c3 |
| 主要按钮 | #08776c / 白字 | 保持足够明暗对比 |

- 默认系统字体：Segoe UI、Noto Sans SC、Microsoft YaHei；不引入外部字体请求。
- 页面标题 28px / 首页 34px，分区标题 17px，正文与控件 13—15px，辅助文字原则上不低于 12px。
- 常用间距 8/12/16/24px，主内容 24×28px；分区圆角 8px、表单 6px。
- 一组操作只突出一个主要按钮；次要操作使用描边或文字。取消/失败同时有文字，不只依赖颜色。
- 路径用可换行/省略的完整地址区域，悬停可查看完整路径；数据表数字对齐，下载速度统一 MiB/s，缺值显示横线。
- 科学相位/相干色标由成果服务定义，不以界面主题色替代。

## 页面规范
首页：简洁任务标题、三个明显操作、最近工程卡。卡片显示名称、Profile、.pilot 位置、最近打开时间、数据选择和运行任务数量。未知任务数显示未知，不伪造进度。
新建：工程名、父文件夹、Profile；提交前显示工程目录与 .pilot 路径。打开：文件选择与只读识别，错误状态明确，旧响应失效。
P01：常驻窄筛选与剩余宽度地图，高度按窗口独立变化。筛选组保留 UTC、ABCD 与 mission 差异；环境状态一行摘要，按需展开配置。
下载审核：目标属于工程或共享 Library、精确目录、场景/角色、复用引用、已知大小/未知项/剩余空间。修改目标或选项立即废弃旧预览，提交引用新计划。
下载任务：首层显示状态、影像数量、所属工程、保存位置和控制；传输按场景/角色显示，任务 ID/接续链藏于任务记录。服务端每页 10 批，支持搜索、状态筛选和翻页。
P02—P05：沿用标题/表单/列表/Inspector 的共用组件与令牌；本轮不新增未经设计的科学参数、步骤或假 QC。

## 交互与性能边界
- 运行中不抢焦点；参数未保存时离开工程需用户处理，失败打开保留原上下文。
- 新页面加载回首页；事件重连不清空用户当前已打开工程。工程关闭不停止后台任务。
- 下载传输、校验、发布与引用分开；无可靠总量不显示伪百分比。暂停确认 worker 停止后才变为已暂停。
- 有活动下载时 3 秒轮询，空闲 15 秒；请求去重，筛选防抖，旧响应丢弃。历史分页不传回整个下载历史。
- 浏览器事件显示仅保留最近 500 条；完整状态仍存数据库并按游标恢复。频繁传输进度合并，不把 stdout 逐行写入事件数据库。
- 每次下载 worker/control 日志独立，记录保留在管理区；科学 Run 日志不可覆盖。详情按需分页读取。
- 键盘焦点可见，面板收起/展开交接焦点；尊重 reduced-motion。原生 125%/150% 缩放、超大清单和完整无障碍审计仍需独立证据。
