## 下一步顺序

1. P01 真实账号认证、长时续传和吞吐独立验收，不将 fixture 结果代替真实结果。
2. 按新用户指令进入 P02 设计，确认数据集、参考影像、EOF、DEM 高程基准、AOI/IW/burst 与缺失项。
3. 在依赖工作前明确 D01：phase stack 为配准复数 SLC、缠绕干涉相位或二者，及 looks/滤波/参考约定。
4. 逐页完成 P03、P04、P05，再规划 NISAR 专属体验。

## 保留与暂缓

保留 ISCE2 官方 TOPS、ISCE3/NISAR/openSEPPO、reader、CLI 旧工程兼容和历史科学证据。解缠、广域相位/GUNW 对照、CUDA、时序与 NISAR 新 UI 暂缓。
基础输入兼容、真实退出、资产可读/shape/sidecar、历史隔离、取消与生命周期仍必须验证。未执行的科学 QC 不标为 PASS。
搬迁/便携备份、系统文件关联、长期容量与崩溃恢复压力验证仍为独立工作。
