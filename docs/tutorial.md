# 第一个检索下载工程

本教程覆盖 1.5.0 已交付的工程与检索下载路径，不代表完整 InSAR 计算教程。

1. 按[安装指南](installation.md)启动 Web 工作台。
2. 新建 Sentinel-1 工程，指定研究目录和名称。
3. 打开“检索与下载”，圈定研究区域并选择日期范围。
4. 执行检索，比较覆盖、日期和轨道条件，将候选影像加入清单。
5. 预览获取内容，选择加入当前工程，按需包含轨道文件与 DEM，核对保存位置后提交。
6. 进入下载中心检查任务。数据就绪后保留来源与校验记录，供后续准备环节使用。

真实下载需要数据服务认证及网络。先用小批次核对结果；本教程不要求大规模计算。
下一环节是数据与准备，其完整页面仍待设计。下载完成不等于参考影像、共同 burst、DEM 高程基准与科学参数均已就绪。
