# 故障排查

## 启动命令不存在

使用安装环境的完整路径 `~/.local/share/insar-pilot/web-venv/bin/insar-pilot`，或先激活环境。旧入口若指向失效 Python，重新按[安装指南](installation.md)安装；不要删除工程或 Library。

## 浏览器无法连接

运行 `insar-pilot --status`，停止时先启动。核对端口与浏览器地址，确认 WSL 仍运行。端口被占用时，用 `--port` 显式选择新端口。

## 窗口显示占用

关闭已进入工作台的其他窗口，等待页自动接续。异常断开约 15 秒释放，重试可能再需数秒。占用与后台任务无关，不需要复制令牌。

## 地图未加载或下载失败

查看错误提示与任务详情，区分底图网络、检索服务、数据认证与目标目录问题。底图失败不代表影像损坏；重试下载不覆盖历史尝试。真实账号长时下载仍有独立验收事项。

## 科学环境缺少组件

检查所选 Python 与组件状态。应用不包含 ISCE2/ISCE3，只负责检测与提示，由用户维护环境。组件可导入不等于科学结果已验证。

## 退出被拒绝

活动任务/worker 存在时，先处理任务再退出。关闭浏览器不会结束后台，不要通过删除状态目录停止任务。
旧 Qt 的 xcb/Wayland 和强制激活 Conda 提示不再适用于 1.5.0。维护旧版本请查阅相应 Git 标签和历史文档。
